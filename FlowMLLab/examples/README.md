# Examples

The three publication workflows are exposed through the installed CLI:

```bash
flowmllab reproduce continuum
flowmllab reproduce pod-deeponet
flowmllab reproduce dsmc
```

The corresponding retained inputs and outputs remain in
`MIE690A_AI_in_Fluid_Mechanics/data/` and
`MIE690A_AI_in_Fluid_Mechanics/results/`. Tutorial notebooks provide annotated
front ends but do not define separate implementations.
